# Appeal Hub

Платформа для работы с обращениями граждан.

## Прототип интерфейса

Откройте `index.html` в браузере (двойной клик или Live Server).

### Экраны

1. **Дашборд** — показатели + таблица всех обращений
2. **Новое обращение** — флоу: поступление документа → AI-обработка → создание карточки
3. **Карточка обращения** — детальный просмотр с историей AI-обработки

### Флоу обработки

1. Документ поступает в систему (drag & drop или выбор файла)
2. AI распознаёт текст и маскирует персональные данные
3. Данные заносятся в систему и отображаются как карточка обращения
4. Обращение появляется в таблице на дашборде
