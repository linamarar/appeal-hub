## DEF-001 — Некорректный SLA в обращениях клиента

| Поле | Значение |
|---|---|
| **ID** | DEF-001 |
| **Приоритет** | P2 |
| **Компонент** | Карточка клиента / SLA |
| **Файлы** | `scripts/services/clients-service.js`, `scripts/services/appeals-service.js` |

**Шаги воспроизведения:**
1. Открыть `#/clients/CL-001`
2. Перейти на вкладку «Обращения»
3. Сравнить колонку SLA с тем же обращением в `#/appeals/:id`

**Ожидание:** SLA-состояние и сообщение совпадают со списком обращений и карточкой.

**Факт:** `ClientsService.getClientAppeals` вызывает `AppealsService.getList(actor)`, передавая объект пользователя вместо `Date`. В `enrich()` это значение попадает в `SlaService.computeState(raw, now)`, что даёт `Invalid Date` и некорректный расчёт SLA.

**Статус:** Open
