## DEF-001 — Колонка «Обновлено» показывает дату создания

- **Приоритет:** P3  
- **Раздел:** Список обращений  
- **Окружение:** Local, Prod  
- **Предусловия:** открыт `#/appeals`  
- **Шаги:** сравнить колонку «Обновлено» с `createdAt`/`updatedAt` в mock  
- **Ожидаемый результат:** `updatedAt`  
- **Фактический результат:** рендер `${a.date}, ${a.time}` (= createdAt)  
- **Воспроизводимость:** всегда  
- **Вероятный модуль:** `scripts/app.js` → `renderTable`  
- **Статус:** Open  

## DEF-002 — Поиск и фильтры не влияют на таблицу

- **Приоритет:** P1  
- **Раздел:** Список обращений  
- **Окружение:** Local, Prod  
- **Предусловия:** список загружен  
- **Шаги:** ввести номер в `#appeals-search`; выбрать статус/приоритет/исполнителя; нажать «Сбросить»  
- **Ожидаемый результат:** таблица и счётчик фильтруются  
- **Фактический результат (до исправления):** `renderTable()` всегда вызывал `AppealsService.getList()` без фильтров; listeners отсутствовали  
- **Исправление:** единое состояние `appealsListFilters` + `filterAppealsList()`; поиск по номеру/теме; фильтры status/priority/assignee; AND; сброс; empty state и счётчик  
- **Повторная проверка:** 2026-08-03 — Local (`node --check`, логическая проверка фильтров на 14 mock-записях) PASS; Prod после публикации `scripts/app.js`  
- **Воспроизводимость:** исправлено  
- **Вероятный модуль:** `scripts/app.js` (`renderTable`, `initAppealsListFilters`, `resetAppealsFilters`)  
- **Статус:** FIXED  

## DEF-003 — Изменения обращений теряются после перезагрузки

- **Приоритет:** P2  
- **Раздел:** Mock persistence  
- **Окружение:** Local, Prod  
- **Предусловия:** изменить статус/комментарий в карточке  
- **Шаги:** убедиться, что список обновился → F5  
- **Ожидаемый результат:** данные сохранены (для демо-стенда)  
- **Фактический результат:** `AppealsRepository.saveRecord` пишет только в in-memory объект; localStorage нет  
- **Воспроизводимость:** всегда  
- **Вероятный модуль:** `scripts/data/appeals-repository.js`  
- **Статус:** Open

## DEF-005 — SLA в таблице обращений клиента считается неверно

- **Приоритет:** P2  
- **Раздел:** Карточка клиента  
- **Окружение:** Local, Prod  
- **Предусловия:** открыть клиента с обращениями  
- **Шаги:** сравнить SLA на карточке клиента и в списке/карточке обращения  
- **Ожидаемый результат:** одинаковый расчёт от текущей даты  
- **Фактический результат:** `ClientsService.getClientAppeals` вызывает `AppealsService.getList(actor)`, где `getList(now)` воспринимает user-объект как `now` → некорректный Date  
- **Воспроизводимость:** всегда  
- **Вероятный модуль:** `scripts/services/clients-service.js`  
- **Статус:** Open
